# BareFoot Explore China — website starter

A responsive, English-language landing page for Fujian outdoor and cultural experience discovery.

## Files
- `index.html` — complete static website (HTML, CSS, and small JavaScript snippet included)

## Publish with GitHub Pages
1. Upload `index.html` to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`, then Save.
5. Wait for the Pages deployment to finish.

The page uses remote Unsplash images, so an internet connection is needed for those photos to load.

## Notes
The page is a starter framework. Replace the placeholder brand/contact details and imagery as needed. This site does not claim to be a travel agency; ensure any real services and arrangements comply with applicable local requirements.
