BareFoot 网站图片管理说明

将整个文件夹内的 index.html 和 images/ 上传到 GitHub 仓库根目录。
注意：GitHub 网页版不能直接上传 zip 作为网站；需要先解压，再上传文件。

四个详情页均为 4 张照片：旧照片作为第 1 张大图，新照片作为其余 3 张。
每个项目的 Highlights 配图使用该项目新增的三张照片。

漳州：images/zhangzhou.jpg（原图）、zhangzhou-tulou.jpg（云水谣土楼）、zhangzhou-river.jpg（云水谣小河）、zhangzhou-path.jpg（云水谣小径）
泉州：images/quanzhou.jpg（原图）、quanzhou-temple.jpg（泉州庙堂）、quanzhou-food.jpg（泉州土笋冻）、quanzhou-feast.jpg（泉州家宴）
龙岩：images/longyan.jpg（原图）、longyan-village.jpg（龙岩大公社）、longyan-buffalo.jpg（龙岩路上牛）、longyan-farmland.jpg（龙岩田园风光）
厦门：images/xiamen.jpg（原图）、xiamen-bikes.jpg（云顶山自行车）、xiamen-mist.jpg（云顶山迷雾）、xiamen-village.jpg（云顶山村庄）

后续替换：打开 GitHub 仓库 > images 文件夹 > 点击要换的文件 > 右上角 ... > Upload files（如果界面没有这个选项，在 images 文件夹点 Add file > Upload files），上传完全同名的新 JPG 文件并提交 Commit changes。若 GitHub 网页拒绝同名覆盖，可先删除旧文件并提交，再上传同名新文件。保持文件名、扩展名和目录不变，不用修改 index.html。

旧文件 background2.png、barefoot-logo.jpg、hero.jpg 也保留。
